# Migraciones históricas de LOTO Games

Estos archivos son copias históricas de las migraciones usadas durante el
desarrollo inicial del ERP/POS.

No deben ejecutarse mediante `supabase db push`.

El directorio activo de migraciones es:

    supabase/migrations/

Las migraciones activas usan timestamps completos y su historial está
sincronizado con el proyecto remoto LotoGamesPOS.

Este directorio se conserva únicamente como referencia y respaldo histórico.
